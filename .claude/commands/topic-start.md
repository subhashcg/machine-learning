Load the `tutor` skill, then start topic $ARGUMENTS on the current step branch.

1. Confirm the branch is right and up to date with `main`.
2. Frame the topic in a short paragraph: why it matters, what it connects to,
   what is genuinely new versus what they half-know already from earlier topics.
3. Ask **four to six prediction questions**. Rules:
   - they answer in chat
   - tell them explicitly not to run the code
   - make the questions expose misconceptions, not recall definitions
   - include at least one "predict the output" and one about cost or memory
4. **Stop there.** Explain nothing until they answer.

Do not write the reference card yet — it comes after the discussion, so it can
reflect what they actually got wrong.
